HTML Semântico

HTML semântico consiste em utilizar elementos que possuem significado para descrever a estrutura da página.

Em vez de utilizar várias <div>, utilizamos tags específicas que descrevem a função de cada parte do site.


Benefícios

  • Código mais organizado
  • Melhor manutenção
  • Melhor SEO
  • Melhor acessibilidade
<header>
<nav>
<main>
<section>
<footer>

Principais Tags Semânticas


Algumas das principais tags utilizadas são:

  • <header> -> Cabeçalho
  • <nav> -> Menu de Navegação
  • <main> -> Conteúdo Principal
  • <section> -> Seção
  • <article> -> Artigo
  • <aside> -> Conteúdo Adicional
  • <footer> -> Rodapé

Essas tags tornam o código mais organizado e ajudam leitores de tela e outras tecnologias assistivas a entenderem melhor a estrutura do site.

<header>
    Logo da empresa
</header>

<nav>
    Início | Produtos | Contato
</nav>

<main>

    <section>
        Serviços
    </section>

    <article>
        Notícia publicada
    </article>

    <aside>
        Sugestões
    </aside>

</main>

<footer>
    © 2026 Empresa
</footer>

Acessibilidade

A acessibilidade busca tornar sites e aplicações utilizáveis pelo maior número possível de pessoas, incluindo usuários com limitações visuais, auditivas ou motoras.


Boas práticas:

  • Textos alternativos
  • Contraste adequado
  • Títulos organizados
  • Navegação por teclado
  • Formulários identificados
<img src="imagem.jpg" 
alt="Descrição da imagem">

Medidas Fixas x Relativas

As medidas relativas permitem que a interface se adapte a diferentes dispositivos.


Medidas Fixas:

  • px -> Pixels
  • cm -> Centímetros

Medidas Relativas:

  • % -> Porcentagem
  • em -> Unidade baseada no tamanho da fonte
  • rem -> Unidade baseada no tamanho da fonte do elemento raiz
  • vw -> Unidade baseada na largura da viewport
  • vh -> Unidade baseada na altura da viewport
.container{
    width:80%;
    font-size:1.5rem;
}

Responsividade

Responsividade é a capacidade de um site adaptar seu layout a diferentes tamanhos de tela.


Objetivos:

  • Melhorar experiência do usuário
  • Evitar barras de rolagem horizontais
  • Permitir acesso em celulares, tablets e computadores
@media(max-width:768px){
    .container{
        flex-direction:column;
    }
}

Flexbox

Flexbox é uma técnica de layout unidimensional que permite criar designs mais flexíveis e responsivos.


Ele organiza elementos em:

  • Linhas
  • Colunas

Muito utilizado em:

  • Menus
  • Cards
  • Alinhamentos
.container{
    display:flex;
    justify-content:center;
    align-items:center;
}

Grid

Grid é uma técnica de layout bidimensional que permite criar designs mais flexíveis e responsivos.


Permite trabalhar simultaneamente com:

  • Linhas
  • Colunas

Muito utilizado em:

  • Layouts Completos
  • Galerias
  • Dashboards
.grid{
    display:grid;
    grid-template-columns:
    1fr 1fr 1fr;
}

Flexbox x Grid


Flexbox:

  • Uma dimensão
  • Componentes Menores
  • Alinhamento Simples

Grid:

  • Duas dimensões
  • Layouts Complexos
  • Controle Preciso
.container{
    display:flex;
    justify-content:center;
    align-items:center;
}

.grid{
    display:grid;
    grid-template-columns:
    1fr 1fr 1fr;
}

Mobile First

Mobile First é uma estratégia onde o desenvolvimento começa pela menor tela primeiro.


Vantagens:

  • Melhor Desempenho
  • Foco no Conteúdo Principal
  • Melhor Experiência Mobile
.card{
    width:100%;
    }

    @media(min-width:768px){
        .card{
        width:50%;
    }
}
